# Tower Defense Game

This is a super, epic tower defense game with insane amounts of difficulty! Only pro Terra players could ever consider attempting to win.

## Technologies

This was made in Godot, my favorite game engine

## Features

There are currently two towers: Archer and Wizard, that each have three upgrades. There are rounds that get increasingly difficult (Round 7 is where it starts to get really rough)

## Bugs

If you line the cursor right between two tiles, you can sometimes place two towers for the price of one (I like to think of this as a BOGO)

Sometimes the projectiles just don't work. They go through the enemy, but don't do damage. I'm not sure why this happens, but it fixes it self.
